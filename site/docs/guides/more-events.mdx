---
title: More events and "+N more"
description: Limit how many events a day shows, render the "+N more" button, and open your own popover with the day's events from the press or the keyboard.
---

When a day of a month (or of the all-day row) holds more events than it should show, the core
hides the rest and says how many: each day's `hiddenCount` and its `hiddenOccurrenceIds`. The
package renders `Calendar.More`, a button that is there only while something is hidden, and
reports its press as the engine's `more-click`. The popover, its list and its words are yours.

<Example id="more-events" />

## Limiting a day's events

`dayMaxEvents` decides how many lanes a day shows:

| value | what a day shows |
| --- | --- |
| `null` | every event (the default): rows grow |
| a number | that many lanes; the others are hidden |
| `"auto"` | as many lanes as fit the room the day gives its events, measured by the engine |

```ts
model.run("settings.set", { settings: { dayMaxEvents: 2 } });
```

With a number, a week row grows to hold its lanes: let it (`flex: 1 0 auto` in a column of rows)
and let the grid scroll. With `"auto"`, the engine measures each day's room and the event height,
so give `Calendar.DayEvents` the height the day leaves (a flex child that grows, `min-height: 0`):
it then holds no lanes of its own, and a resize of the calendar measures again.

## The "+N more" button

`Calendar.More` goes in a `Calendar.Day`. It renders only while `hiddenCount` is more than zero,
and its children are elements or a function of its state (in Vue, its default slot's scope:
`hiddenCount`, `hiddenOccurrenceIds`, `date`):

<Framework name="react">

```tsx
<Calendar.Day day={day} className="day">
    <Calendar.DayEvents className="events">
        {(segment) => <EventSegment segment={segment} />}
    </Calendar.DayEvents>
    <Calendar.More className="more">
        {({ hiddenCount }) => `+${hiddenCount} more`}
    </Calendar.More>
</Calendar.Day>
```

</Framework>

<Framework name="vue">

```vue
<Calendar.Day :day="day" class="day">
    <Calendar.DayEvents v-slot="{ segment }" class="events">
        <EventSegment :segment="segment" />
    </Calendar.DayEvents>
    <Calendar.More v-slot="{ hiddenCount }" class="more">
        +{{ hiddenCount }} more
    </Calendar.More>
</Calendar.Day>
```

</Framework>

On the keyboard it is the last item of the day's events: Down from the day's last event focuses
it, Enter on a day whose events are all hidden focuses it, Up goes back and Escape returns to the
day. It stays outside the roving focus (`tabindex="-1"`), so Tab never stops on it.

## Opening a popover from the more click

A press on the button, Enter on it, or an assistive technology's click is the engine's
`more-click`, which the root reports (`onMoreClick` in React, `@more-click` in Vue) with the day
and the hidden occurrences. The popover opens from that callback.

<Framework name="react">

With Fragiola UI's popover, `Calendar.More` is the trigger it is anchored to (`render`), and the
trigger's own toggle is cancelled, since the engine's event already says when to open:

```tsx
import {
    Calendar,
    createCalendarModel,
    useCalendar,
} from "@fragiola/calendar-react";
import { useState } from "react";
import { Popover } from "#/components/ui/popover";

export function BusyMonth() {
    const [model] = useState(() =>
        createCalendarModel({
            version: 1,
            events: [],
            calendars: [],
            settings: { dayMaxEvents: 2 },
            view: { type: "month", anchorDate: "2026-11-26" },
        }),
    );
    // the day whose popover is open
    const [open, setOpen] = useState<string | null>(null);
    return (
        <Calendar.Root model={model} onMoreClick={(event) => setOpen(event.date)}>
            <Calendar.DayGrid aria-label="Month">
                <Calendar.Weeks>
                    {(week) => (
                        <Calendar.Week week={week} className="week">
                            {(day) => (
                                <Calendar.Day day={day} className="day">
                                    <Calendar.DayEvents>
                                        {(segment) => (
                                            <Calendar.Segment segment={segment} />
                                        )}
                                    </Calendar.DayEvents>
                                    <MorePopover
                                        date={day.date}
                                        open={open === day.date}
                                        onClose={() => setOpen(null)}
                                    />
                                </Calendar.Day>
                            )}
                        </Calendar.Week>
                    )}
                </Calendar.Weeks>
            </Calendar.DayGrid>
        </Calendar.Root>
    );
}

function MorePopover(props: { date: string; open: boolean; onClose: () => void }) {
    const { model } = useCalendar();
    const items =
        model.get("list").days.find((day) => day.date === props.date)?.items ?? [];
    return (
        <Popover.Root
            open={props.open}
            onOpenChange={(next, details) => {
                // the engine's more-click opens it: the trigger's own toggle would undo it
                if (details.reason === "trigger-press") details.cancel();
                else if (!next) props.onClose();
            }}
        >
            <Popover.Trigger
                render={
                    <Calendar.More className="more">
                        {({ hiddenCount }) => `+${hiddenCount} more`}
                    </Calendar.More>
                }
            />
            <Popover.Content align="start">
                <ul>
                    {items.map((item) => (
                        <li key={item.occurrenceId}>
                            {model.get("event-by", { id: item.eventId })?.title}
                        </li>
                    ))}
                </ul>
            </Popover.Content>
        </Popover.Root>
    );
}
```

</Framework>

<Framework name="vue">

With Fragiola UI's popover (on Reka UI), `Calendar.More` is the trigger it is anchored to
(`as-child`). The popover's `open` is the app's: the trigger's own toggle asks to open it, which
the engine's event already did, and only a close is heard:

```vue title="busy-month.vue"
<script setup lang="ts">
import { Calendar, createCalendarModel } from "@fragiola/calendar-vue";
import { ref } from "vue";
import MorePopover from "./more-popover.vue";

const model = createCalendarModel({
    version: 1,
    events: [],
    calendars: [],
    settings: { dayMaxEvents: 2 },
    view: { type: "month", anchorDate: "2026-11-26" },
});
// the day whose popover is open
const open = ref<string | null>(null);
</script>

<template>
    <Calendar.Root :model="model" @more-click="(event) => (open = event.date)">
        <Calendar.DayGrid aria-label="Month">
            <Calendar.Weeks v-slot="{ week }">
                <Calendar.Week :week="week" class="week">
                    <template #day="{ day }">
                        <Calendar.Day :day="day" class="day">
                            <Calendar.DayEvents v-slot="{ segment }">
                                <Calendar.Segment :segment="segment" />
                            </Calendar.DayEvents>
                            <MorePopover
                                :date="day.date"
                                :open="open === day.date"
                                @close="open = null"
                            />
                        </Calendar.Day>
                    </template>
                </Calendar.Week>
            </Calendar.Weeks>
        </Calendar.DayGrid>
    </Calendar.Root>
</template>
```

```vue title="more-popover.vue"
<script setup lang="ts">
import { Calendar, useCalendar } from "@fragiola/calendar-vue";
import { Popover } from "#/components/ui/popover";

const props = defineProps<{ date: string; open: boolean }>();
const emit = defineEmits<{ close: [] }>();
const { model } = useCalendar();

/** The day's events, read as the open popover renders. */
function items() {
    return model.get("list").days.find((day) => day.date === props.date)?.items ?? [];
}
</script>

<template>
    <Popover.Root :open="open" @update:open="(next) => !next && emit('close')">
        <Popover.Trigger as-child>
            <Calendar.More v-slot="{ hiddenCount }" class="more">
                +{{ hiddenCount }} more
            </Calendar.More>
        </Popover.Trigger>
        <Popover.Content align="start">
            <ul>
                <li v-for="item in items()" :key="item.occurrenceId">
                    {{ model.get("event-by", { id: item.eventId })?.title }}
                </li>
            </ul>
        </Popover.Content>
    </Popover.Root>
</template>
```

</Framework>

The popover lists every event of the day, not only the hidden ones: `model.get("list")` gives
any view's visible days with their occurrences. Escape and a press outside close it.

<Framework name="react">

The children function of `Calendar.Weeks` closes over `open`: when it changes, the rows render
again with the new value, so the right day's popover opens. See
[Composition](/docs/concepts/composition) for when a children function is called again.

</Framework>

<Framework name="vue">

The days' slot reads `open`, a ref: when it changes, the rows render again with the new value, so
the right day's popover opens. See [Composition](/docs/concepts/composition) for when a slot is
called again.

</Framework>

## Opening the day instead

A popover is one choice. The month example switches to the `day` view on the day and shows it as
an agenda:

<Framework name="react">

```tsx
<Calendar.Root
    model={model}
    onMoreClick={({ date }) => {
        model.run("view.set", { type: "day" });
        model.run("view.go-to", { date });
    }}
>
    {/* the month, or the day as a Calendar.List */}
</Calendar.Root>
```

</Framework>

<Framework name="vue">

```vue
<script setup lang="ts">
function openDay({ date }: { date: string }) {
    model.run("view.set", { type: "day" });
    model.run("view.go-to", { date });
}
</script>

<template>
    <Calendar.Root :model="model" @more-click="openDay">
        <!-- the month, or the day as a Calendar.List -->
    </Calendar.Root>
</template>
```

</Framework>

See [List view](/docs/guides/list-view) for the agenda's parts.
