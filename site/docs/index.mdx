<Features columns={4}>
<Feature title="Views">
Month, week, day, any number of days and a list, laid out by the core: lanes for all-day events,
overlap columns for timed ones, "+N more" when a day is full.
</Feature>
<Feature title="Interaction">
Select a range, drag an event across days and between the all-day row and the time grid, resize
it, drop something from outside: with the pointer, a touch or the keyboard.
</Feature>
<Feature title="Exact dates">
Time zones and daylight saving time with `Intl` only, RFC 5545 recurrence with edit scopes, and
an injectable clock. No date library, no runtime dependency.
</Feature>
<Feature title="A typed JSON model">
The calendar is data, typed by your registry: load it, save it, and veto or rewrite every command
with middleware, from a click, a server or an assistant.
</Feature>
</Features>

<Section title="What it never ships">
<Pills strike items={["CSS", "Icons", "Text", "Event editors", "Popovers", "Date pickers"]} />

The state is exposed as `data-*` attributes and ARIA, so any styling solution works: Tailwind,
plain CSS, CSS modules, CSS-in-JS. Dates and titles are data you format; the examples use
Fragiola UI and its palettes.
</Section>
