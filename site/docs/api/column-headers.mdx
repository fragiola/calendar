---
title: Calendar.ColumnHeaders
description: The grid's header row. It calls your function per column, a time grid's days or a month's weekdays, inside a row of its own.
---

`Calendar.ColumnHeaders` is the header row of a grid (`role="row"`). It renders a `div` and calls
your children function once per column: each day of a time grid, or each day of a month's first
row (standing for its weekday). What a header says is yours, from `useDayHeader`'s `Intl` parts.

## Behaviour

- The dates are the view's columns: hidden days (`hiddenDays`) are left out, and the order follows
  `firstDayOfWeek` and the direction.
- It calls the function again for a date whose column changed, and for every date when the
  function itself is a new one (React's contract): an inline function is always current; declare
  it outside the component, or with `useCallback`, to re-render only what changed (see
  [performance](/docs/guides/performance)).
- In a time grid, the time axis is column 1 (`aria-colindex` on each header): leave its room
  with your layout (a padding or the grid template), no corner cell is needed.

It renders `data-calendar-part="column-headers"`.

## Usage

<Framework name="react">

```tsx
import { Calendar, useDayHeader } from "@fragiola/calendar-react";

// the weekday and the day in a time grid, the weekday in a month, in the calendar's locale
function DayHeader({ date }: { date: string }) {
    const parts = useDayHeader(date);
    return (
        <Calendar.ColumnHeader date={date} className="header">
            {parts.map((part) => part.value).join("")}
        </Calendar.ColumnHeader>
    );
}

const header = (date: string) => <DayHeader date={date} />;

<Calendar.ColumnHeaders className="headers">{header}</Calendar.ColumnHeaders>;
```

</Framework>

<Framework name="vue">

```vue title="day-header.vue"
<script setup lang="ts">
import { Calendar, useDayHeader } from "@fragiola/calendar-vue";

// the weekday and the day in a time grid, the weekday in a month, in the calendar's locale
const props = defineProps<{ date: string }>();
const parts = useDayHeader(() => props.date);
</script>

<template>

    <Calendar.ColumnHeader :date="date" class="header">
        {{ parts.map((part) => part.value).join("") }}
    </Calendar.ColumnHeader>
</template>
```

```vue
<Calendar.ColumnHeaders v-slot="{ date }" class="headers">
    <DayHeader :date="date" />
</Calendar.ColumnHeaders>
```

</Framework>

<Framework name="angular">

```ts title="day-header.ts"
import { Component, input } from "@angular/core";
import { injectDayHeader } from "@fragiola/calendar-angular";

// the weekday and the day in a time grid, the weekday in a month, in the calendar's locale
@Component({ selector: "[appDayHeader]", template: "{{ text() }}" })
export class DayHeader {
    readonly appDayHeader = input.required<string>();
    private readonly parts = injectDayHeader(() => this.appDayHeader());
    text() {
        return this.parts().map((part) => part.value).join("");
    }
}
```

```html
<div calendarColumnHeaders class="headers">
    <ng-template calendarColumnHeadersItem let-date>
        <div [calendarColumnHeader]="date" [appDayHeader]="date" class="header"></div>
    </ng-template>
</div>
```

</Framework>

## Props

`ColumnHeadersProps`; it also takes the [common props](/docs/api/root#common-props) and every `div`
attribute.

In Vue: the same props (in kebab-case in a template), and slots in place of `children`; see
[Vue primitives](/docs/api/vue).

In Angular: a directive on your element, the props as its inputs, templates in place of
`children`; see [Angular primitives](/docs/api/angular).

| prop | type | description |
| --- | --- | --- |
| `children` | `(date: string) => ReactNode` | called per column with its day, `YYYY-MM-DD`; render a `Calendar.ColumnHeader` |

## State

`ColumnHeadersState`:

| field | type | description |
| --- | --- | --- |
| `dates` | `readonly string[]` | the columns' days: a time grid's, or a month's first row |
