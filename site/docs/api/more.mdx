description: A day's "+N more" trigger, rendered while some of its events do not fit. A press is the engine's more-click; the popover is yours.

`Calendar.More` is a day's "+N more" `button`. It renders only while some of the day's
occurrences do not fit under the `dayMaxEvents` setting, and hands you how many and which. The
popover, dialog or agenda it opens is yours.

## Behaviour

- It renders nothing while the day's `hiddenCount` is 0.
- A press, Enter on it, or an assistive technology's click is the engine's `more-click`
  (`onMoreClick`, with the day's `date` and the hidden `occurrenceIds`): open your popover from
  there. The engine takes Enter and prevents the native click, so a popover trigger rendered as it
  would never toggle from the keyboard: control the popover's `open` from `onMoreClick`.
- On the keyboard it is the last item of the day's events: Down from the last event reaches it,
  Enter on a day whose events are all hidden focuses it, Up goes back, Escape returns to the day.
  It stays `tabindex="-1"`, outside the roving focus.

It renders `data-calendar-part="more"` and `data-date`.

## Usage

<Framework name="react">

```tsx
import { Calendar } from "@fragiola/calendar-react";
import { type ReactNode, useState } from "react";

function BusyMonth() {
    const [openDay, setOpenDay] = useState<string | null>(null);
    return (
        <Calendar.Root
            settings={{ dayMaxEvents: 2 }}
            onMoreClick={(event) => setOpenDay(event.date)}
        >
            <Calendar.DayGrid aria-label="Month">
                <Calendar.Weeks>
                    {(week) => (
                        <Calendar.Week week={week}>
                            {(day) => (
                                <Calendar.Day day={day}>
                                    <Calendar.DayEvents>
                                        {(segment) => <Calendar.Segment segment={segment} />}
                                    </Calendar.DayEvents>
                                    <Calendar.More className="more">
                                        {({ hiddenCount }) => `+${hiddenCount} more`}
                                    </Calendar.More>
                                    {openDay === day.date ? (
                                        <DayPopover date={day.date} onClose={() => setOpenDay(null)} />
                                    ) : null}
                                </Calendar.Day>
                            )}
                        </Calendar.Week>
                    )}
                </Calendar.Weeks>
            </Calendar.DayGrid>
        </Calendar.Root>
    );
}

// your popover: the day's events from model.get("list"), a close button
declare function DayPopover(props: { date: string; onClose: () => void }): ReactNode;
```

</Framework>

<Framework name="vue">

```vue title="busy-month.vue"
<script setup lang="ts">
import { Calendar } from "@fragiola/calendar-vue";
import { ref } from "vue";
// your popover: the day's events from model.get("list"), a close button
import DayPopover from "./day-popover.vue";

const openDay = ref<string | null>(null);
</script>

<template>

    <Calendar.Root :settings="{ dayMaxEvents: 2 }" @more-click="openDay = $event.date">
        <Calendar.DayGrid aria-label="Month">
            <Calendar.Weeks v-slot="{ week }">
                <Calendar.Week :week="week">
                    <template #day="{ day }">
                        <Calendar.Day :day="day">
                            <Calendar.DayEvents v-slot="{ segment }">
                                <Calendar.Segment :segment="segment" />
                            </Calendar.DayEvents>
                            <Calendar.More v-slot="{ hiddenCount }" class="more">
                                +{{ hiddenCount }} more
                            </Calendar.More>
                            <DayPopover
                                v-if="openDay === day.date"
                                :date="day.date"
                                @close="openDay = null"
                            />
                        </Calendar.Day>
                    </template>
                </Calendar.Week>
            </Calendar.Weeks>
        </Calendar.DayGrid>
    </Calendar.Root>
</template>
```

</Framework>

<Framework name="angular">

```ts title="busy-month.ts"
import { Component, signal } from "@angular/core";
import { CALENDAR } from "@fragiola/calendar-angular";
// your popover: the day's events from model.get("list"), a close button
import { DayPopover } from "./day-popover";

@Component({
    selector: "app-busy-month",
    imports: [CALENDAR, DayPopover],
    template: `
        <div calendarRoot [settings]="{ dayMaxEvents: 2 }" (moreClick)="openDay.set($event.date)">
            <div calendarDayGrid aria-label="Month">
                <ng-template calendarWeeks let-week>
                    <div [calendarWeek]="week">
                        <ng-template calendarDays let-day>
                            <div [calendarDay]="day">
                                <div calendarDayEvents>
                                    <ng-template calendarDayEventsItem let-segment>
                                        <div [calendarSegment]="segment"></div>
                                    </ng-template>
                                </div>
                                <button *calendarMore="let more" class="more">+{{ more.hiddenCount }} more</button>
                                @if (openDay() === day.date) {
                                    <app-day-popover [date]="day.date" (closed)="openDay.set(null)" />
                                }
                            </div>
                        </ng-template>
                    </div>
                </ng-template>
            </div>
        </div>
    `,
})
export class BusyMonth {
    readonly openDay = signal<string | null>(null);
}
```

</Framework>

The rows' function closes over `openDay`, so it is called again when the open day changes (React's
contract); in Vue, the slot reads the `openDay` ref, and Vue renders the rows again when it changes; in
Angular, the days' template reads the `openDay()` signal, checked with the template it is in. The [more events guide](/docs/guides/more-events) builds the popover with Fragiola UI.

## Props

`MoreProps`; it also takes the [common props](/docs/api/root#common-props) and every `button`
attribute.

In Vue: the same props (in kebab-case in a template), and slots in place of `children`; see
[Vue primitives](/docs/api/vue).

In Angular: a directive on your element, the props as its inputs, templates in place of
`children`; see [Angular primitives](/docs/api/angular).

| prop | type | description |
| --- | --- | --- |
| `children` | `ReactNode \| (state) => ReactNode` | what it shows, or a function of its state (`({ hiddenCount }) => …`) |

## State

`MoreState`:

| field | type | description |
| --- | --- | --- |
| `hiddenCount` | `number` | how many occurrences of the day do not fit |
| `hiddenOccurrenceIds` | `readonly string[]` | their ids, for your popover |
| `date` | `string` | the day, `YYYY-MM-DD` |
