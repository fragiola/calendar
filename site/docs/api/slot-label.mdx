---
title: Calendar.SlotLabel
description: A slot row's label, the row header that shows the time you format, read as data from useSlotLabel and never rendered by the library.
---

`Calendar.SlotLabel` is the header of a slot row: a `div` with `role="rowheader"` and `data-time`.
It renders what you give it; the library writes no time as text. The time's words come from
`useSlotLabel(time)` (`Intl` parts in the calendar's locale) or your own formatting.

## Behaviour

- The row's `rowheader` in the APG [grid pattern](https://www.w3.org/WAI/ARIA/apg/patterns/grid/):
  screen readers announce it with the row's cells.
- It is outside the roving focus (the slots are the cells you move over).
- It must be inside a `Calendar.SlotRow`.

## Usage

<Framework name="react">

```tsx
import { Calendar, useSlotLabel } from "@fragiola/calendar-react";

function HourText(props: { time: string }) {
    // Intl parts in the calendar's locale: "9 AM", "09"
    const parts = useSlotLabel(props.time, { hour: "numeric" });
    return <span>{parts.map((part) => part.value).join("")}</span>;
}

export function Label() {
    return (
        <Calendar.SlotLabel className="slot-label">
            {({ time }) => (time.endsWith(":00") ? <HourText time={time} /> : null)}
        </Calendar.SlotLabel>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="hour-text.vue"
<script setup lang="ts">
import { useSlotLabel } from "@fragiola/calendar-vue";

const props = defineProps<{ time: string }>();
// Intl parts in the calendar's locale: "9 AM", "09"
const parts = useSlotLabel(() => props.time, { hour: "numeric" });
</script>

<template>

    <span>{{ parts.map((part) => part.value).join("") }}</span>
</template>
```

```vue title="label.vue"
<script setup lang="ts">
import { Calendar } from "@fragiola/calendar-vue";
import HourText from "./hour-text.vue";
</script>

<template>

    <Calendar.SlotLabel v-slot="{ time }" class="slot-label">
        <HourText v-if="time.endsWith(':00')" :time="time" />
    </Calendar.SlotLabel>
</template>
```

</Framework>

<Framework name="angular">

```ts title="hour-text.ts"
import { Component, input } from "@angular/core";
import { injectSlotLabel } from "@fragiola/calendar-angular";

@Component({ selector: "app-hour-text", template: "<span>{{ text() }}</span>" })
export class HourText {
    readonly time = input.required<string>();
    // Intl parts in the calendar's locale: "9 AM", "09"
    private readonly parts = injectSlotLabel(() => this.time(), { hour: "numeric" });
    text() {
        return this.parts().map((part) => part.value).join("");
    }
}
```

```html title="label.html"
<!-- imports: [CALENDAR, HourText] -->
<div calendarSlotLabel #label="calendarSlotLabel" class="slot-label">
    @if (label.state()?.time?.endsWith(":00")) {
        <app-hour-text [time]="label.state()!.time" />
    }
</div>
```

</Framework>

It shows the hour on the full hours and nothing on the other slots. See
[`useSlotLabel`](/docs/api/hooks).

## Attributes

| attribute | value |
| --- | --- |
| `data-calendar-part` | `data-calendar-part="slot-label"` |
| `data-time` | the slot's start, `HH:mm` |
| `role` | `rowheader` |

## Props

In Vue: the same props (in kebab-case in a template), and slots in place of `children`; see
[Vue primitives](/docs/api/vue).

In Angular: a directive on your element, the props as its inputs, templates in place of
`children`; see [Angular primitives](/docs/api/angular).

`SlotLabelProps` takes the [common props](/docs/api/root#common-props) and any `div` attribute,
and:

| prop | type | description |
| --- | --- | --- |
| `children` | `ReactNode`, or `(state: SlotLabelState) => ReactNode` | what it shows: elements, or a function of its state |

## State

`SlotLabelState`:

| field | type | description |
| --- | --- | --- |
| `time` | `string` | the slot's wall-clock start, `HH:mm` (`useSlotLabel(time)` gives it as parts) |
