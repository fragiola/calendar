# @fragiola/calendar

The framework-free core of [Fragiola Calendar](https://fragiola.com/calendar): a headless,
accessible event calendar. It holds the calendar document (events, calendars, settings) and its
JSON Schemas, the date and time-zone engine (`Intl` only, zero runtime dependencies), the model
and its commands, the views and their layout, and the engine that binds one calendar on screen to
the DOM. It ships no CSS, no text and no framework code: the React, Vue and Angular adapters
render it.

Not released yet: the package is in development (`0.0.0`).
